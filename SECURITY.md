# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of
`gh-repobootstrapper`. Development builds and versions that are no longer the
latest release are not supported.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Please report it via GitHub Security Advisories:
`https://github.com/kkamegawa/gh-repobootstrapper/security/advisories/new`.
We will acknowledge reports within seven calendar days and provide a status update after triage.

Do not include secrets, access tokens, or private repository content in a
report.
